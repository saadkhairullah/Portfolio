Overview

A ~40k line multi-service framework for the Linux build of the Blockheads server, built on a network protocol and save format I reverse engineered myself. It runs a live server for 300+ players and has held off 20+ real DDoS attacks.

Why I built it

Blockheads is an old game with no developer support left and not much community support either. I ran my own hobby server for a few months and kept hearing the same two things from players: they wanted functionality the game never shipped, and servers were getting taken down daily by malicious script kiddies using unpatched vulnerabilities nobody was ever going to fix.

There were two half-finished pieces floating around: a database writer for the game, and a proxy that forwarded packets and logged their raw bytes. Only about four packets had ever been reverse engineered, and those were the easy ones: unserialize them, print them, and the fields are already readable. The packets I needed were nothing like that. Nothing was built on top of any of it either.

I started by using those two tools purely to understand how the game actually works. The database writer showed me how the game stores its world and its players, and the proxy let me watch what the server and client say to each other. Once I understood that, I could start building on it.

What made it hard

The save data is zipped and stored as binary plists, so nothing was readable up front. I also needed several separate services to talk to each other in real time without stepping on each other.

The hardest single thing was finding the player location packet. Most of what I wanted to build depended on knowing where players were, and there was no documentation for any of it.

I sat in Wireshark for hours watching traffic and moving a character around until I could pin down which packet changed. Then I had to work out whether the values were little endian or big endian before any of it meant anything.

Getting attacked while building it

All of this was happening while the server was live. Players kept requesting features, and I kept getting hit with DoS attacks through the same vulnerabilities I was trying to work around. So I turned the proxy into an application layer sanitizer that drops bad ENet packets and connections before they reach the server.

Where it is now

It works as a framework for the Linux ELF build of the Blockheads server binary. Server hosts can run modified servers with custom functionality, built on top of the game's database structure, its network packets, and hooks into certain functions at runtime. As far as I know nothing else like it exists for this game.

The server I run on it has over 300 registered players from all over the world. It has taken well over 1000 hours across four months and it is still in progress, mostly because the community keeps growing and more hosts keep asking to use it.
