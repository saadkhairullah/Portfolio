Overview

A free, fully local AI interviewer that runs on your own machine. Speech to speech, a real technical round, and none of your interview data leaves your computer.

Why we built it

Students preparing for interviews do not have a cheap way to practice. Everything decent is a paid service, and the free options are not good enough to be worth the time. We wanted something a student could just download and use, at no cost, as many times as they want.

Training the model

I fine-tuned a Q4 quantized 7B Qwen model on 60+ real interviews, each one running 20 minutes to an hour. The size and the quantization were both deliberate: it has to fit on hardware a student actually owns.

Training kept dying on out of memory errors. I got past it with gradient checkpointing and Liger kernels, which cut memory use enough to finish the runs on the hardware I had.

Getting it onto real machines

The first version ran on vLLM, which meant it only worked on Nvidia GPUs. That left out Mac users and anyone on AMD, so we added a llama.cpp path alongside it. Both are bundled into a downloadable Tauri app, so inference, speech to text, text to speech and all the processing happen on your own hardware.

The interview itself is a full technical round: 50 packaged LeetCode style questions, picked at random, conducted out loud. If your machine cannot handle it, there is a hosted web version instead. We did not want to pay for a dedicated GPU server just to keep it running, so users plug in their own free Gemini API key and run interviews on the latest Gemini models at no cost. That side is a Next.js frontend on Vercel with the backend on GCP Cloud Run.
