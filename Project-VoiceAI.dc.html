Overview

A business idea taken to production in 31 hours. A voice agent that behaves like a real healthcare patient, calling clinics to probe how they actually handle people on the phone.

How it works

The agent runs off scenario files, so what it wants out of the call is something you pick up front. There are 17 scenarios to choose from. If the patient needs to cancel an appointment, you select that one and the agent places the call and handles the conversation on its own.

Calls go out over Telnyx, which came out cheapest for outbound. Deepgram does both the speech to text and the text to speech, which is what keeps the conversation sounding natural instead of stilted. Silero VAD handles turn-taking so the agent knows when the other person has actually finished talking, and Llama 3.3 70B decides what to say next.

What made it hard

The worst part was the voice activity detection. Out of the box it treated background noise as someone talking, so the agent would cut itself off or sit there waiting on a room that was already quiet. I ended up tuning the VAD thresholds so it only registers speech above a certain volume, which is what made the turn-taking usable on real calls instead of just in a quiet room.

Where it landed

60+ real calls for under $2 total. The whole point was to find out whether the idea held up before putting real time into it, so I built it over a weekend and ran it against actual clinics.
