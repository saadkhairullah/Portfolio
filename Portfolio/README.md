## Selected Work

### [Blockheads Server Framework](https://github.com/saadkhairullah/The-Blockheads-Server)
`Java` `TypeScript` `Python` `LMDB` `Ghidra` `Wireshark` `iptables`

Reverse-engineered a closed-source UDP/ENet game protocol with Ghidra and Wireshark, then built a ~40k-line multi-service framework around it: live database manipulation, packet injection and blocking, protocol-level mod support, and an automated TypeScript bot. Services communicate over Unix Domain Sockets.

| | |
|---|---|
| **300+** | registered players served in production |
| **20s → <5ms** | query latency after redesigning the LMDB schema |
| **20+** | live DDoS attacks mitigated |

### [AI Interviewer](https://github.com/vkr-vavilla/Senior_Design) &nbsp;·&nbsp; [live demo](https://senior-design-seven.vercel.app/login)
`PyTorch` `HuggingFace` `QLoRA` `vLLM` `FastAPI` `Tauri`

A cost-efficient 7B Qwen model fine-tuned with QLoRA on 60+ real interview datasets, wrapped in a downloadable cross-platform Tauri app so anyone can run it free. Voice-to-voice: it conducts a software engineering interview and scores it, on consumer hardware. Async FastAPI backend handles concurrent JWT-secured sessions; vLLM serves inference in under 500ms end to end.

### [TXUML: Texas Underground Mine Locator](https://github.com/saadkhairullah/TXUML) &nbsp;·&nbsp; [txuml.vercel.app](https://txuml-saad-khairullahs-projects.vercel.app/)
`Next.js` `TypeScript` `React` `MongoDB` `MapboxGL` `GeoJSON`

A live interactive GIS system mapping poorly documented underground coal mines across Texas and where their operations occurred, so builders and home buyers can avoid constructing on century-old workings. I originated the concept after spotting the gap, then led a team of 5 in Agile through to production.

**350+** mines mapped and live.

### [Healthcare Voice AI Agent](https://github.com/saadkhairullah/Telepohone-Voice-Assistant-Patient)
`FastAPI` `Pipecat` `Telnyx` `Deepgram` `Silero VAD` `Llama 3.3 70B`

An agentic system that autonomously places outbound calls to clinics and holds a real voice-to-voice conversation as a patient, probing service quality. Real-time turn-taking and agentic decisioning. Built solo in 31 hours to test a business idea: **60+ production calls for under $2 total.**
